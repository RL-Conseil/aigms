# Slide 2 — Pourquoi maintenant ?

## Les usages IA arrivent plus vite que leur gouvernance

Chez les PME/ETI, on observe généralement :

- adoption rapide de copilotes et IA SaaS ;
- Shadow AI ;
- données internes envoyées à des services externes ;
- multiplication des fournisseurs et agents ;
- décisions métier partiellement automatisées ;
- manque de registre unique ;
- responsabilité diffuse ;
- sécurité et conformité traitées après coup.

**Message clé :**  
L’infrastructure peut être correctement hébergée tout en laissant un **risque de gouvernance non traité**.

**Visuel :**  
`Utilisateurs → SaaS IA / Agents / API → Données → Cloud / Hosting` avec un point d’interrogation sur « Qui gouverne ? ».

# Slide 14 — Pourquoi cette approche est crédible

## Elle ne promet pas de « certifier par logiciel »

La méthode distingue :

- exigences normatives ;
- guidance ;
- politique interne ;
- décision humaine ;
- contrôle technique ;
- preuve.

AIGMS peut :
- structurer ;
- rappeler ;
- tracer ;
- agréger ;
- mapper ;
- alerter.

AIGMS ne peut pas :
- accepter un risque à la place du client ;
- rendre un avis juridique définitif ;
- garantir une certification ;
- remplacer l’auditeur externe.

**Message :**
La confiance vient de la traçabilité et de l’efficacité du système de management.
