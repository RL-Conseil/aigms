# Décisions d'architecture (ADR)

Une décision est consignée ici lorsqu'elle est structurante : elle engage la
sécurité, le modèle de domaine ou la façon dont les règles de gouvernance sont
appliquées, et la revenir coûterait cher.

Format : contexte, décision, conséquences, alternatives écartées.
Numérotation continue, jamais réutilisée. Un ADR remplacé n'est pas supprimé :
il est marqué « remplacé par ADR-XXXX ».
